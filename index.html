Bridge

I wrote down a bidding system and published it.

Bridge bidding is a language two partners speak in a very small vocabulary under very strict rules — which makes it exactly the kind of thing worth formalizing. So I formalized mine, and put it on Amazon.

And then the obvious next step

If a bidding system can be written down as rules, it can be learned from data. I've been building a model that takes a hand and a bidding history and picks a rational bid — then trains toward bids that score statistically better. Hands generated with deal, scored, and fed back in.
