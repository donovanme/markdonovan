TriviaBot privacy policy

Last updated 18 November 2026

What TriviaBot is

TriviaBot is a private program run by Mark Donovan on his own computer to publish videos to the Instant Trivia YouTube channel. It is not offered to the public and has one user: the owner of that channel.

What it accesses

TriviaBot uses YouTube API Services. When the channel owner signs in with Google, it receives permission to manage that one YouTube channel, and uses it only to upload videos, set their titles, descriptions, thumbnails and publish times, manage the channel's playlists and read the channel's own video details.

What it stores and shares

  • The sign-in token Google issues is kept in a file on the owner's computer. It is sent to Google when TriviaBot talks to YouTube and to nobody else.
  • TriviaBot does not collect, store or share personal information about viewers, subscribers or anyone else.
  • Nothing is sold, and nothing is passed to third parties.

YouTube and Google

Because TriviaBot uses YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy also apply. TriviaBot's access can be removed at any time from the Google account's third-party connections page.

These web pages

The TriviaBot pages set no cookies and load no analytics or third-party scripts. The site is hosted on GitHub Pages, which may log visitors' IP addresses as part of running the service.
